# 零界 / ZERO LINE

可离线运行的 Three.js 第一人称射击训练场.所有模型由程序生成, 包含 6 个会移动, 持枪射击和执行关节动画的敌人.

## 启动

**保留整个项目文件夹, 双击 `index.html`, 点击"进入训练场".**

不需要安装依赖, 启动服务器, 联网或执行构建命令.推荐使用支持 WebGL 2 的桌面 Chrome / Edge.第一次点击按钮用于获取鼠标锁定和启用音效; 如果浏览器拒绝鼠标锁定, 可按住右键拖动视角.暂停时点击"继续训练"重新锁定鼠标.

运行所需文件只有 `index.html`, `scene-layout.js`, `models/` 和 `vendor/`.不要只复制 HTML.

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 观察 | WASD / 鼠标 |
| 连续射击 | 按住鼠标左键 |
| 换弹 | R, 弹匣 30 发, 备用弹药无限 |
| 跳跃 / 奔跑 | Space / Shift |
| 暂停 | Esc; 窗口失焦也会暂停 |
| 自由飞行调试 | B, 开启时自动显示碰撞线框 |
| 调试升降 / 加速 | Space, Ctrl / Shift |
| 声音 | 右上角按钮 |

调试模式自动以绿色线框显示实际参与碰撞的盒子, 线框可透过遮挡观察, 退出时隐藏.调试模式无重力, 可穿墙, 免伤; W/S 沿镜头的完整朝向飞行, 包括上下俯仰.调试时暂停玩家射击和敌人开火, 敌人仍移动.退出调试如果位于墙内或下方没有场景碰撞体支撑, 会回到出生点; 无可用碰撞体时保留飞行.

清除全部敌人即完成训练.头部命中造成双倍伤害.雷达中的橙色圆点表示存活敌人.死亡或完成后可重新部署.

## 模型工厂接口

模型通过普通脚本注册, 不使用 import/export:

```js
FPS.models.example = (THREE, options) => {
  const root = new THREE.Group();
  // 在这个文件内创建几何体, 材质, 子节点.
  return { root };
};
```

主程序按 `scene-layout.js` 的 `catalog` 加载脚本, 再按 `instances` 调用工厂.必须返回有效的 Three.js `Object3D` 作为 `root`.模块不能创建自己的计时器或动画循环.

可选返回属性:

- `update(dt, api)`: 由主循环调用, `dt` 为秒.敌人使用通用 API; 挂在相机上的武器收到 `{ time, walk, recoil, reload }` 动画输入.
- `damage(amount, api)`, `alive`: 主程序据此将实例作为可受击角色; `root.userData.actor` 由主程序自动关联.子网格可使用 `userData.zone = 'head'` 标记头部.
- `muzzle`: 枪口节点, 主程序用其世界坐标显示火光和曳光.
- 临时特效返回 `duration`, 到期自动移除并释放资源.临时特效不要与常驻模型共享可释放材质或几何体.

敌人使用的通用 API:

| 接口 | 用途 |
| --- | --- |
| `player`, `eye()` | 玩家脚底位置/生命/调试状态, 以及玩家眼睛世界坐标 |
| `move(root, dx, dz, radius, height)` | 水平碰撞移动, 返回实际移动距离 |
| `visible(from, to)` | 检查场景固体是否遮挡视线 |
| `shoot(from, direction, team, damage)` | 通用射线射击, 方向为归一化向量, team 为 player 或 enemy |
| `effect(name, options)` | 尝试创建临时特效, 失败不影响射击判定 |
| `killed(actor)` | 记录击杀; 敌人仅在首次死亡时调用 |

## 布局约定

- 单位为米, Y 轴向上, 欧拉角为弧度, 采用 XYZ 顺序.
- 每个实例包含 `id`, `model`, `position`, `rotation`, `scale`, `collision`; `options` 传给模型工厂.
- `collision.enabled` 控制是否参与静态移动碰撞及遮挡射击.启用时提供局部 `size` 和可选 `offset`; 复杂外形可用 `boxes: [{ size, offset }, ...]` 声明多个盒子.掩体的底座, 墙身和顶盖分别配置, 避免把底座宽度用于整个高度.
- 碰撞盒应用实例变换后取世界轴对齐包围盒.任意旋转可用, 但斜放物体的碰撞会保守扩大; 当前布局采用直角旋转, 避免明显偏差.
- 玩家移动使用半径 0.32 米的圆形水平截面, 接触墙面时相机中心会保留身体半径的距离.撞墙时将最后一步细分到接触位置, 不再整步撤回; 拐角也不再用方形角色包围盒扩大阻挡范围.
- `attach: 'camera'` 表示相机挂载的第一人称武器.其他元素挂载到场景.
- 地面模型局部厚度 .5, 中心位于 0, 因此实例 Y 为 -.25 时上表面为 0.敌人模型原点为脚底.
- 初始元素由布局定义, 射击火光/曳光等临时对象由主程序创建.
- 动态敌人碰撞场景障碍; 当前版本没有敌人间的推挤和复杂寻路.避障适合开阔训练场, 不保证复杂迷宫通行.
- 运行中直接改布局文件不会热更新; 保存后刷新 HTML.

## 容错

文件缺失, 语法错误, 注册失败, 构造异常和更新异常都会显示在页面错误面板.失败的模型跳过, 失败实例不保留隐形碰撞.角色更新异常时停用该角色, 并从任务目标数量中排除.错误消息合并, 避免逐帧刷屏.

布局整体不可用时保留可进入的空场景并自动启用无重力飞行.模型特效失败不会影响射击, 命中或伤害.Three.js 缺失或 WebGL 不可用时, 保留错误说明及重新加载按钮; 此时无法继续渲染 3D 游戏.

容错旨在隔离可恢复的缺失和异常; 同页面脚本中的死循环, 内存耗尽或恶意修改共享全局变量不属于可隔离故障.

## 开发工具(玩家不需要执行)

按用户要求, 后续修改不自动运行游戏, 浏览器, 测试或截图; 用户自行打开 `index.html` 验证.下列命令仅保留为手动开发工具.

依赖版本锁定在 `package-lock.json`.`npm ci` 仅用于安装开发工具.

- `npm run build:vendor`: 重新生成已随项目交付的本地 Three.js 脚本.无需在每次修改模型时执行.
- `npm test`: 使用本机 Chrome, 通过离线 `file://` 页面验证启动, 动画, 移动, 碰撞, 跳跃, 飞行, 射击, 换弹, 遮挡, 敌人伤害, 暂停, 胜负, 以及模块故障注入.可通过 `CHROME_PATH` 指定 Chrome 可执行文件.
- 测试截图放在已忽略的 `artifacts/`, 故障注入使用临时目录, 不会破坏源文件.
- 调试控制台 `FPS.inspect()` 提供运行状态与实例引用; 它不会启动额外主循环.

只编辑项目源码; `vendor/three.min.js` 是生成依赖, 保留上游许可证, 不手工维护.
